# RGB からスペクトルへ: 避けられない誤差と、モーメントの数

RGB のレンダラーも、RGB からスペクトルを作る変換も、表面を「D65 の下の RGB」としてしか知りません。この情報だけで、別の光（タングステン、ろうそく、LED）の下の色を、どこまで当てられるかを調べました（2026-11-08）。Peters らのモーメント表現（2019）の参照コードを使い、「モーメントを何個持てば、光を変えても色が保証されるか」も測っています。

計算の全出力: [metamer_mismatch_results.txt](data/metamer_mismatch_results.txt)。スクリプト: `tools/studies/metamer_mismatch.py`。

## 1. 何を測ったか

D65 の RGB が同じ、有界な反射率（0 ≤ R(λ) ≤ 1）の集合は凸集合で、本当の反射率はその 1 つです（メタマーの集合）。別の光の下では、集合のメンバーごとに色が違います（メタマーのミスマッチ。Wyszecki と Stiles、Finlayson と Morovic、Logvinenko らの先行研究がある。書誌は未確認）。その色の広がりが、**どんな変換でも避けられない誤差**です。どのスペクトルを選んでも、本当は別のメンバーかもしれないからです。

- 方向ごとの線形計画（scipy の HiGHS）で、広がりの端の色を求めます（150 方向）。
- **半径**: 1 つの推定値の、最悪の場合の ΔE00 のうち、最小のもの（頂点と重心を候補にした近似。上から押さえる値）。
- 拘束の種類: (a) D65 の色（3 つの数）、(b) さらになめらかさ（曲率が、そのスペクトル自身の最大曲率の f 倍以下）、(c) 位相のコサインモーメント m 個（Peters らの「鏡像の信号」の版。波長のワープあり／なし）。
- スペクトル: 実測の布 11 点（ラボのデータ。430〜700 nm を使い、[0, 1] に切り、5 nm の移動平均）と、金のフレネル反射率 4 本（垂直・60°、反射 1 回・3 回）。光源は、A、ろうそく、LED。

## 3. 読み方

1. **事前知識なしの下限は、大きすぎて、変換を比べる物差しになりません。** D65 の色だけでは、布で 17〜22、金で 9〜12 です。現行の変換の実際の誤差（0.6〜1.8）が小さいのは、実在の反射率がなめらかだからです（変換は、最もなめらかなスペクトルを選ぶ）。なめらかさの拘束を足しても、半径は 6〜11 に残ります。**変換の良し悪しを決めるには、実在の反射率の集合（統計的な事前知識）が要ります。** 手元の布 11 点は、少なすぎます。
2. **ワープ付きの 3 モーメントは、D65 の色とほぼ同じ情報です**（布 17.2 と 16.8）。論文の主張と整合し、この実装（位相に対する測度、ワープ）の確認になります。ワープなしの 3〜5 モーメントは、保証がほとんどありません（布で 32〜48）。
3. **モーメントを増やすと、光を変えたときの保証が狭まります。** 金（なだらかな 1 段の立ち上がり）は、6 個で A・ろうそくの下の最悪の差が 2 以下になります。布は、10 個でも 4〜5 です。LED のように尖った光は、もっと要ります（布 8.6、金 2.5）。光が尖るほど、必要な個数が増えます。
4. **これは「最悪の場合」の保証で、最大エントロピーの復元（実際の MESE）の誤差ではありません。** 後者はずっと小さいはずですが、未測定です。

## 4. 限界

- 布は 11 点（うち 6 点は、3 種類の布の 2 点ずつ）、金は 4 本。5 nm 格子、150 方向。半径は近似です。
- 布の実測は、両端（430 nm 未満、700 nm 超）が信用できないため、整形しています。
- Peters らの論文本体は、まだ読めていません（補助コードだけ）。「メタマーのミスマッチ」と「モーメントの数」を結びつける形（拘束を三刺激値から m 個のモーメントに替える）が、既存研究にあるかは、文献の確認が要ります。
- 知覚の評価（何個で弁別できなくなるか）は、被験者が要るので未実施です。

## 5. 次の手

- 最大エントロピーの復元（参照コードの bounded MESE）で、実際の誤差をモーメント数の関数として測る。金の F(λ)ⁿ（多重反射）も。
- 結果の使いみち: 余地が小さければ「入れても効果なし」と書く（Jakob-Hanika のときと同じ）。大きければ、RGB からモーメントへの表（付属の C++ で作る）を試す。

## 再現

```bash
python -I tools/studies/metamer_mismatch.py --smooth 1,2,4 --moments 3,4,5,6,8,10 --dirs 150
python -I tools/studies/metamer_mismatch.py --moments 3,4,5,6,8,10 --dirs 150 --warp references/peters2019/ReferenceImplementation.py
```

`--warp` は、Peters らの参照コード（BSD 3-clause、`references/peters2019/`。リポジトリには入れていない）を、パスで読み込んで使います。
