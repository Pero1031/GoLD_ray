# 偏光（最小版）

光の偏光状態を Stokes ベクトル、界面の作用を Mueller 行列で追い、**ガラス・水面・金属・薄膜で反射・屈折した光の偏光**を画像にします。カメラの前に偏光フィルターを置いた画像も出せます。

- コード: `include/Core/Polarization.hpp`（Stokes・Mueller・Fresnel の振幅）、`Integrator.cpp` の `updatePolarization`、`Dielectric::scatterMueller`
- 自己チェック: `GoLD_rayt.exe --scene polarization`（Fresnel の閉じた式、Mueller の連鎖と 3 次元の電場の直接計算との照合、ガラスで反射した光線の Stokes ベクトル）
- 使い方: `--stokes`（`<out>_S0..S3.pfm`、偏光度 `_dolp.png`、偏光角 `_aolp.png`）、`--polarizer 0,45,90`（偏光フィルター越しの画像 `<out>_pol0.png` ...）

## 考え方

経路をカメラから追い、偏光を知っている材質（滑らかなガラス・水面での反射と屈折、金属の反射、薄膜の反射と透過）の事象に Mueller 行列を掛けます。拡散面・粗い誘電体・媒質中の散乱に当たったら、その先の光は無偏光として扱います。光源を直接サンプルする光（NEE）も、その頂点の Mueller 行列を通して数えます。無偏光の光は Stokes ベクトルが (L, 0, 0, 0) なので、カメラで見える偏光は「連鎖の 1 列目 × スカラーの放射輝度」です。既存のスカラーの経路追跡は変えず、偏光は隣で足し込むだけです。`--stokes` なしの画像は変わりません。

## 例

`--scene sea --stokes --polarizer 0,90`（800×450、64 spp、RGB の開発ビルドで 46 秒）。水平の偏光フィルター（0°）では、海面の反射（水平に偏光している）が残り、水中の石はほとんど見えません。垂直（90°）では、反射が弱まって、石がはっきり見えます。偏光フィルターで水面のてかりを消す、あのよく知られた効果です。

シャボン玉（`scenes/soap_bubble.json --stokes --polarizer 0,90`、900×900、96 spp、RGB の開発ビルドで 35 秒）では、入射面が縦になる泡の上下の反射が、水平のフィルターでは明るく、垂直では暗くなります（膜の干渉の色はそのままです）。

金の球（`--scene gold --stokes`）は、偏光度が小さく（正面ではほぼ 0）、斜めに入射する縁ほど強くなります。偏光の向きは、球の縁に沿った（接線の）向きです。

## 約束事

- Stokes ベクトルは、光の進む向き k と、基準の向き x（y = k × x）で表します。S1 > 0 は x に沿った直線偏光、S2 > 0 は x と y の間の 45° です。画像の基準は、カメラの右向きです。
- 界面の基底は (s, p, k)。s は入射面に垂直、p = k × s。Fresnel の振幅は Born & Wolf のもので、垂直入射で r_p = −r_s です。
- 各鏡面の事象は「Mueller 行列 ÷ 第 1 要素」を連鎖に右から掛けます。第 1 要素（無偏光の反射率・透過率）は、既存の経路の重みがすでに持っています。事象と事象のあいだの基底の回転は `basisChange` です。

## 限界

- 対応する材質は、誘電体（滑らかなガラス・水）と金属（`RoughConductor`、粗さは問いません）です。金属は、マイクロファセット法線（ハーフベクトル）での複素 Fresnel 振幅を使い、多重散乱の項は無偏光として混ぜます。薄膜（`thinFilm`）は、膜の多重反射を含む複素振幅（反射と透過）から Mueller 行列を作ります。スペクトルビルドは経路の波長ごとに、RGB ビルドは各チャンネルの波長の重みで積分して、(cos θ, 厚さ) の表にします（初めて使うときに作ります）。コート、粗い誘電体は、偏光を消す扱いです。
- 光源と環境光は無偏光です。偏光した光源、複屈折、媒質中の偏光は入っていません。
- 光子マップ（コースティクス）、`--lvc`、多様体 NEE が足す光は無偏光です。
