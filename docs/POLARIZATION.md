# 偏光（最小版）

光の偏光状態を Stokes ベクトル、界面の作用を Mueller 行列で追い、**滑らかなガラス・水面で反射・屈折した光の偏光**を画像にします。カメラの前に偏光フィルターを置いた画像も出せます。

- コード: `include/Core/Polarization.hpp`（Stokes・Mueller・Fresnel の振幅）、`Integrator.cpp` の `updatePolarization`、`Dielectric::specularEvent`
- 自己チェック: `GoLD_rayt.exe --scene polarization`（Fresnel の閉じた式、Mueller の連鎖と 3 次元の電場の直接計算との照合、ガラスで反射した光線の Stokes ベクトル）
- 使い方: `--stokes`（`<out>_S0..S3.pfm`、偏光度 `_dolp.png`、偏光角 `_aolp.png`）、`--polarizer 0,45,90`（偏光フィルター越しの画像 `<out>_pol0.png` ...）

## 考え方

経路をカメラから追い、**最初の鏡面連鎖**（滑らかなガラス・水面での反射と屈折）だけ Mueller 行列を掛けます。拡散面・粗い面・媒質中の散乱に当たったら、その先の光は無偏光として扱います。無偏光の光は Stokes ベクトルが (L, 0, 0, 0) なので、カメラで見える偏光は「連鎖の 1 列目 × スカラーの放射輝度」です。既存のスカラーの経路追跡は変えず、偏光は隣で足し込むだけです。`--stokes` なしの画像は変わりません。

## 例

`--scene sea --stokes --polarizer 0,90`（800×450、64 spp、RGB の開発ビルドで 46 秒）。水平の偏光フィルター（0°）では、海面の反射（水平に偏光している）が残り、水中の石はほとんど見えません。垂直（90°）では、反射が弱まって、石がはっきり見えます。偏光フィルターで水面のてかりを消す、あのよく知られた効果です。

## 約束事

- Stokes ベクトルは、光の進む向き k と、基準の向き x（y = k × x）で表します。S1 > 0 は x に沿った直線偏光、S2 > 0 は x と y の間の 45° です。画像の基準は、カメラの右向きです。
- 界面の基底は (s, p, k)。s は入射面に垂直、p = k × s。Fresnel の振幅は Born & Wolf のもので、垂直入射で r_p = −r_s です。
- 各鏡面の事象は「Mueller 行列 ÷ 第 1 要素」を連鎖に右から掛けます。第 1 要素（無偏光の反射率・透過率）は、既存の経路の重みがすでに持っています。事象と事象のあいだの基底の回転は `basisChange` です。

## 限界

- 対応する材質は、滑らかな誘電体（ガラス・水）だけです。金属、薄膜、コート、粗い面は、鏡面でも偏光を消す扱いです。
- 光源と環境光は無偏光です。偏光した光源、複屈折、媒質中の偏光は入っていません。
- 光子マップ（コースティクス）、`--lvc`、多様体 NEE が足す光は無偏光です。
